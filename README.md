# Deplark / 速栈 for agentskill.sh

Quickly deploy static websites and Node.js apps for fast access from mainland China. 快速部署站点，让中国大陆用户高速访问。

This is the agentskill.sh distribution source for [@larksq/deplark](https://agentskill.sh/@larksq/deplark). The three-file Skill carries `registration_source: agentskill` into the first browser account connection automatically. It has no credentials or project binding. Installing does not grant account access or deploy a site.

[Create a Deplark account](https://deplark.com/app?utm_source=agentskill&utm_medium=skill&utm_campaign=skill_distribution) · [Read the Skill](skills/deplark/SKILL.md) · [Main repository and other editions](https://github.com/larksq/deplark-skills)

The dependency-free client matches the official Deplark client; the uploader is pinned by SHA-256. Use Node.js 24. Browser connection and persistent credentials currently require macOS; other systems can use an existing account Key via `DEPLARK_API_KEY`. Keep Keys out of chat, source files and command arguments.

Only first account creation counts as registration; later sign-ins do not. An earlier tagged website visit retains its first-source attribution. Hosting service charges are separate from the MIT-licensed Skill.
